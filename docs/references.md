# 內容查核與參考來源

查核日期：2026-07-14｜用途：教材內容正確性依據，僅參考數值與概念，未重製任何外部圖片。

## 物理量與單位

- 國際單位制（SI）基本單位：長度公尺（m）、質量公斤（kg）、時間秒（s）。體積為導出單位（m³），1 mL = 1 cm³、1 L = 1000 mL。
  來源：BIPM《The International System of Units (SI Brochure, 9th ed.)》(https://www.bipm.org/en/publications/si-brochure)；國家度量衡標準實驗室 (https://www.nml.org.tw/)。

## 測量方法（國中理化通則）

- 測量紀錄＝準確值＋一位估計值（記錄到最小刻度的下一位）；量筒讀數視線與凹液面最低處水平，俯視偏高、仰視偏低；上皿天平先歸零校平、待測物置左盤、砝碼以鑷子由大到小置右盤。
  來源：十二年國教自然科學領域課程綱要與國中自然（理化）通行教科書共同內容；交叉核對均一教育平台「基本測量」單元 (https://www.junyiacademy.org/)。

## 密度數值（約值，常溫常壓）

| 物質 | 密度 (g/cm³) |
|---|---|
| 純水（4 °C） | 1.00 |
| 冰（0 °C） | 0.92 |
| 酒精（乙醇） | 0.79 |
| 松木 | 約 0.5 |
| 鋁 | 2.70 |
| 鐵 | 7.87 |
| 銅 | 8.96 |
| 金 | 19.3 |
| 死海湖水 | 約 1.24 |

來源：CRC Handbook of Chemistry and Physics（常見物質密度標準值）；死海鹽水密度交叉核對 Encyclopaedia Britannica「Dead Sea」條目與 Israel Oceanographic and Limnological Research 公開資料（約 1.24 kg/L）。人體平均密度約 0.98 g/cm³（略小於水，肺部充氣時），來源：常見生理學教科書數值。

- 冰浮於水時約 92% 體積在水下：由密度比 0.92/1.00 依阿基米德原理計算。

## 有效數字規則

- 非零數字有效；夾於中間的 0 有效；前導 0 無效；小數末尾的 0 有效。
  來源：通行國中、高中理化教科書及大學普通物理教材共同規則。

## 誤差概念

- 系統誤差（儀器/方法造成、同方向偏移、以校正改善）與隨機誤差（偶然因素、方向不定、以多次測量取平均減少）；準確度＝接近真值程度、精密度＝多次測量的一致性。
  來源：通行理化教科書與 NIST/GUM 測量不確定度基本概念之簡化教學版。
